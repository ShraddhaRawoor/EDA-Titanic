# Task 5 - Exploratory Data Analysis (EDA) on Titanic Dataset

## Project Overview

This project was completed as part of the Data Analyst Internship Task 5. The objective was to perform Exploratory Data Analysis (EDA) on the Titanic dataset using Python and data visualization libraries to identify patterns, trends, relationships, and insights.

## Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The Titanic dataset contains passenger information such as:

* Passenger ID
* Passenger Class (Pclass)
* Name
* Sex
* Age
* Fare
* Embarked Port
* Survival Status

## EDA Tasks Performed

### Data Understanding

* Dataset Preview using `head()`
* Dataset Information using `info()`
* Statistical Summary using `describe()`
* Missing Value Analysis

### Univariate Analysis

* Age Distribution (Histogram)
* Fare Distribution (Boxplot)

### Bivariate Analysis

* Survival by Gender
* Age vs Fare Scatter Plot

### Correlation Analysis

* Correlation Heatmap
* Pairplot Visualization

## Key Findings

* Female passengers had a significantly higher survival rate than male passengers.
* Passenger class had a strong influence on survival probability.
* Most passengers were between 20 and 40 years old.
* Fare distribution contained several outliers.
* Higher fare-paying passengers generally had better survival chances.
* Missing values were mainly present in the Age and Cabin columns.
